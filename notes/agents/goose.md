# Goose

> Block 开源 · 本地运行的 Agent · 开源（Apache-2.0）

## 是什么

Block 开源的本地 Agent。跑在你自己机器上，通过 MCP 扩展能力，并且自带一套 recipe，把常见任务写成可复用的流程。

## 技术形态

- **MCP 是唯一的扩展方式**：能力都做成 MCP server（官方叫 extension），装上就多一批工具。
- **recipe 是可分享的任务单元**：一段带指令和工具清单的文件，可以被版本管理、可以互相传。
- **完全本地**：模型可以指向云端，也可以指向本地模型；执行全在本机。
- **有 IDE 侧边栏**：除了终端，也提供编辑器里的面板。

## 我的使用结论

**适合**：想要本地、可扩展、可分享工作流的团队；把内部系统包成 MCP 之后，recipe 能变成团队的公共资产。

**不适合**：追求开箱即用的体验；它更偏框架 + 生态，不是那种打磨到顺手的产品。

**和其他工具比**：和 dsh 有点像，都把本地运行 + 可扩展 + 工作流当成核心卖点。区别是 goose 的扩展单位是 MCP 和 recipe，dsh 的编排单位是子代理和工作流脚本。前者更贴近 Unix 工具哲学，后者更贴近应用形态。
