# Devin

> Cognition · 云端自主软件工程师 · 闭源 SaaS

## 是什么

Cognition 做的 AI 软件工程师。和本地 Agent 不同，它跑在云端容器里，有自己的浏览器、终端和 IDE，通过 Slack 或网页交活，产出通常是 Pull Request。

## 技术形态

- **云端沙箱**：每个会话有自己的环境，可以装依赖、跑服务、访问网页。
- **任务以异步工单形式存在**：你交一个描述，它在后台干，几十分钟后带着 PR 回来，长任务不占你本地资源。
- **多会话并行**：可以同时开多个会话各干各的。
- **有专门的会话回放**：能看到它每一步点了什么、跑了什么。
- **与 GitHub 深度集成**：clone 仓库、开分支、提 PR 都在流程内。

## 我的使用结论

**适合**：把明确、可验收、耗人力的活儿外包出去：批量迁移、补测试、写文档、跨仓库的小改动。异步交付这一点对不打断我当前工作很友好。

**不适合**：涉及本地未公开环境、依赖内部凭据的活儿；也不适合需要频繁来回对话纠偏的需求。沟通延迟是云端异步的固有成本。

**和其他工具比**：Devin 更像一个初级工程师的异步工位，而不是一个在你终端里并肩工作的同事。它和 Cursor / Claude Code 的差别不只是形态，而是协作模型：一个是交工单等交付，一个是实时协作。
