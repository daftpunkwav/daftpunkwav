# Codex CLI

> OpenAI · 终端 CLI · 开源（Apache-2.0）

## 是什么

OpenAI 的开源编码 Agent CLI，也是 ChatGPT 网页版 Codex 能力的终端版本。它在本地仓库里跑：读文件、改文件、执行命令，模型可以调用本地沙箱里的命令。

## 技术形态

- **开源且可自托管**：代码在 GitHub 上，模型后端可以指向官方 API，也可以指向兼容 OpenAI 协议的其他服务。
- **沙箱是默认前提**：命令执行默认被限制在沙箱里，越界需要显式批准，批准策略可以写进配置或项目文件。
- **配置即代码**：`config.toml` 里能写模型、审批策略、MCP server、项目级指令，支持多层叠加（用户级 / 项目级 / 命令行）。
- **MCP 原生**：外部工具按 `mcp__<server>__<tool>` 暴露，模型调用时直接看到。
- **会话可续**：可以压缩历史、恢复之前的会话继续干活。

## 我的使用结论

**适合**：把任务拆成明确步骤、按清单执行的那种活儿：重构一批文件、跑迁移脚本、照着 spec 改接口。指令明确时它的执行路径很干净，不容易自作主张扩展范围。

**不适合**：需要长篇推理才能定方向的探索性任务；以及完全不能接受模型偶尔跑偏的场景，审批模式要开到最严才有心理负担。

**和其他工具比**：我把它当 Claude Code 的对照组使用：同一道题丢给两边，比的不是谁写得漂亮，而是谁的改动更容易被审。Codex CLI 的 diff 更小、更集中；Claude Code 一次改动常常更大但更完整。
