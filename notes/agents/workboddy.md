# WorkBuddy

> 腾讯 · 桌面端办公 Agent · 闭源产品（有社区生态与教程）

## 是什么

腾讯的桌面端 Agent 产品，定位偏办公场景的 AI 同事：文件处理、知识管理、信息整理、内容生产这一类通用工作，而不是纯代码开发。

## 技术形态

- **桌面 App + 账号体系**：有国内版和国际版两套，账号、额度、积分是核心概念。
- **Skills 与连接器**：把可复用的工作方式做成 Skill，把外部系统做成连接器。社区教程里明确有打造 Skill、连接器、API 与自动化这几章。
- **多 Agent 团队**：社区蓝皮书里有专门的多 Agent 系统设计和自动化可靠性章节，定位是可以把单次任务升级成一支 AI 团队。
- **可被别的工具接进来**：社区有现成项目把 WorkBuddy 桌面 App 里的模型直接接进 DeepSeek Harness，也有把它包装成 OpenAI 兼容接口的网关。

## 我的使用结论

**适合**：和办公文档、资料整理、流程自动化打交道的场景；以及国内网络环境下的日常使用。

**不适合**：写代码。它不是编码工具，代码能力只是顺带；也不适合需要深度定制运行时的场景，客户端是封闭的。

**和其他工具比**：它和我常用的一类 Agent 工具链是两条路：终端 Agent 面向工程任务，WorkBuddy 面向知识工作。值得注意的是它被生态当成模型和账号的来源来用（各种网关和转接方案）。这说明真正被需要的能力是**稳定的模型接入**，不是桌面界面本身。
