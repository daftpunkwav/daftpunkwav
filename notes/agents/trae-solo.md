# TRAE SOLO

> 字节跳动 · TRAE IDE 的 SOLO 模式 · 闭源

## 是什么

字节跳动 TRAE IDE 里的 SOLO 模式。和常见的多轮对话式 Agent 不同，SOLO 的设计目标是一次性把一个完整需求跑完：它自己做上下文工程、自己出计划、自己一路执行到底。

## 技术形态

- **SOLO Flow**：一条从需求到交付的流水线，内部会先做上下文工程，把相关的代码、文档、历史提交组织好再动手。
- **和普通模式共存**：同一个 IDE 里既有交互式问答，也有 SOLO 这种长链路模式，可以按任务大小选。
- **规则可配**：项目规则文件用来固定约定，Agent 每次都读。
- **VS Code 系**：基于 VS Code 分支，扩展和调试生态可用。

## 我的使用结论

**适合**：目标明确、范围清楚的中大型任务，交给它一次跑完比来回对话省事；也适合国内网络环境下使用。

**不适合**：需要每一步都介入的探索性工作；以及要求执行过程完全可审计的场合。

**和其他工具比**：SOLO 的先组织上下文、再一口气执行和我做 [wave-code](https://github.com/daftpunkwav/wave-code) 时的思路是同一个方向：Agent 能不能把长任务跑完，关键在状态和上下文怎么管，而不是单次回答有多聪明。
