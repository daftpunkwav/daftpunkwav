# OpenCode

> SST · 终端 AI 编码代理 · 开源

## 是什么

SST 团队做的开源终端编码代理。定位是 provider 无关的客户端：模型、后端、部署方式都可以自己换，工具层是一套本地命令。

## 技术形态

- **client / server 分离**：核心是一个本地服务，终端 UI、桌面端、IDE 插件都作为客户端接进来，能力不会因为换前端就丢掉。
- **模型不绑定**：内置一批 provider 适配，也能接 OpenAI 兼容接口或自建网关。和我自己的 [breakwater](https://github.com/daftpunkwav/breakwater) 这类网关是天然搭配的组合。
- **LSP 接入**：不只是改文本，能调用语言服务器的诊断信息，类型错误能反馈回 Agent。
- **MCP 支持**：外部工具按统一协议接进来。
- **可共享会话**：会话是服务端状态，可以把一个会话链接出去让别人接手或旁观。

## 我的使用结论

**适合**：想换模型、想接自建网关、想把会话搬到别的界面继续的人。它把 Agent 跑在哪、界面是什么、模型是谁这三件事解耦了，对做基础设施的人友好。

**不适合**：希望开箱即用、不想配置 provider 的场景；以及对可读性要求高的团队。它更像给工程师用的工具，不是给业务同学用的。

**和其他工具比**：和 Claude Code / Codex CLI 比，OpenCode 的开放性明显更高，代价是默认体验没那么打磨过。我做基础设施和网关实验时更愿意用它，因为它把模型接缝暴露在外面，改起来直接。
