# Claude Code

> Anthropic · 终端 CLI（另有 IDE / Web / GitHub Action 入口）· 闭源分发

## 是什么

Anthropic 官方的编码 Agent。核心形态是一条终端里的对话：它读仓库、改文件、跑命令、调用 MCP 工具，权限判断和工具执行都在本地进程里完成。同一个产品也接进了 IDE 插件、网页端和 GitHub Actions。

## 技术形态

- **工具集是白名单**：读写文件、执行命令、搜索、联网这类动作都是显式工具，不是让模型自由发挥。
- **权限有三档**：每次动作前询问、允许过的模式自动放行、直接执行。放行记录落在本地配置里。
- **MCP 是扩展主渠道**：外部能力基本都通过 MCP server 接进来，配置在项目级或用户级。
- **上下文管理靠压缩**：接近上限时把旧对话摘要成一份摘要继续，而不是硬截断。
- **Skills / 自定义命令**：把重复的工作流（检查、发布、审查）固化成可复用的说明与脚本。

## 我的使用结论

**适合**：需要「读懂整个仓库再动手」的活儿，尤其是重构、跨文件改动、追一个只在代码里才说得清的问题。它的长上下文和工具调用质量目前仍然是第一梯队。

**不适合**：要求严格可复现的批量改动；要求每次工具调用都有结构化审计的场景（它更像一个称职同事，不是流水线组件）。

**和其他工具比**：和 Codex CLI 是最像的一对——两个都能直接改仓库。习惯上我更信 Codex 在「按明确步骤执行」时的听话程度，Claude Code 在「需求说得含糊时」更会自己补齐上下文。Cursor 的内置补全和 inline edit 在写小改动时更快，Claude Code 更适合整块任务。
