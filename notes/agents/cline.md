# Cline

> VS Code 扩展 · 开源（Apache-2.0）

## 是什么

装在 VS Code 里的开源编码 Agent。核心交互是 Plan / Act 两段式：先在 Plan 模式里讨论清楚要改什么，确认后再切到 Act 模式真的动手。

## 技术形态

- **Plan / Act 双模式**：Plan 模式只读代码、只输出方案；Act 模式才允许改文件和执行命令。切换是一次显式动作，避免「说着说着就改了」。
- **每步都要批准**：工具调用逐次展示，批准、拒绝、修改参数都可行。
- **MCP 支持**：外部服务通过 MCP 接入。
- **自带浏览器能力**：通过 Playwright 驱动浏览器，是较早把「Agent 能操作网页」做进产品的扩展之一。
- **Checkpoint**：改动可以打回滚点，实验性尝试不至于弄脏工作区。

## 我的使用结论

**适合**：想在 IDE 里看着 Agent 干活、并且要能逐步把关的场景；以及需要用 MCP 把内部工具接进来的团队。

**不适合**：批量、长链路的无人值守任务——逐步批准的模型在这里是负担而不是安全网。

**和其他工具比**：和 Claude Code / Codex CLI 相比，Cline 把控制权交回给人的程度更高，适合需要过程可见的场合；代价是效率低、上下文容易被逐步批准打断。它也是开源方案里 MCP 生态最成熟的一个，值得当参考实现读。
