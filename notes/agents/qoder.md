# Qoder

> 阿里 · agentic IDE · 闭源（可下载客户端）

## 是什么

阿里推出的 agentic IDE，形态是 VS Code 的分支。和「在编辑器里加个聊天框」不同，它把「仓库理解」和「按规格执行」做成了产品级功能。

## 技术形态

- **Repo Wiki**：先给仓库建一份可查询的知识索引，Agent 回答「这个功能在哪实现」时不用每次从头扫代码。
- **Quest 模式（规格驱动）**：先写一份需求/任务描述，Agent 把它展开成计划再执行，适合任务边界清楚的大改动。
- **多种 Agent 角色**：偏通用问答的、偏执行的分开，可以按任务类型切换。
- **模型可选**：除自家模型外也接了第三方模型。
- **IDE 本体**：补全、diff 视图、终端、调试器都在一个客户端里。

## 我的使用结论

**适合**：想「先说清需求再让它干」的项目，尤其是有明确 spec 的改造；以及需要快速理解陌生仓库的时候。

**不适合**：本地环境复杂、依赖内部服务的活儿；以及习惯纯终端工作流的人——它的重心在 IDE 内完成。

**和其他工具比**：Qoder 的 Repo Wiki + Quest 模式，是这批 IDE 系 Agent 里比较完整的一套「规格 → 计划 → 执行」链条，和 Cursor 的 inline 补全体验是两种取向：Cursor 帮你写得快，Qoder 更想帮你把活儿派清楚。
