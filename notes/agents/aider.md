# Aider

> 终端里的结对编程 · 开源 · Python

## 是什么

老牌终端 AI 结对编程工具。形态很朴素：你在终端里聊天，它把改动直接落到你本地的 git 仓库里。

## 技术形态

- **git 是主心骨**：Aider 的每一次改动都会自动提交，帮你把 AI 的修改切成可回滚的若干 commit，历史干净可查。
- **仓库地图（repo map）**：用 tree-sitter 解析代码，抽取符号并按引用关系做图排序，把「最相关的骨架」放进上下文，而不是把整个仓库塞进去。
- **双模型分工**：一个「架构模型」负责出方案，一个「编辑模型」负责把方案落成代码，两次调用换来质量。
- **两种模式**：`/ask` 只答不做，`/architect` 先规划再执行。
- **支持多种模型服务**：包括本地模型。

## 我的使用结论

**适合**：在已有仓库里做边界清楚的重构，并且希望每一步都能用 git 回滚；也适合当「只读问答」工具用。

**不适合**：从零搭一个大项目——它对「从需求到结构」的规划能力一般；也没有现在这批 Agent 那么强的自主长程执行能力。

**和其他工具比**：Aider 是「会帮你把 commit 整理好」的那一类，思路更接近一个老练的结对伙伴，而不是自主代理。它出现在我的工具列表里，更多是因为它把 repo map 这件事做得很干净，值得抄。
