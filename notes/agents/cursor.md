# Cursor

> Anysphere · IDE（VS Code 内核）· 闭源，团队版可自托管模型

## 是什么

基于 VS Code 分支做的 AI IDE。区别于在编辑器里塞个聊天框，它把模型做成了编辑器的一等能力：补全、inline edit、agent 模式、后台任务，都长在原来的编辑体验里。

## 技术形态

- **补全是主力入口**：整行 / 多行补全，按你的实际修改（不只是光标位置）预测下一段代码，接第三方模型做低延迟推理。
- **Agent 模式在编辑器内执行**：能读文件、跑终端、搜索、调用 MCP，并把改动直接落到工作区。
- **Rules / 自定义指令**：项目级规则文件 + 随时引用的记忆，用来固定这个仓库该怎么写。
- **模型可自选也可自带**：团队版可以把模型网关指到自己的服务。

## 我的使用结论

**适合**：日常开发的主场。补全和 inline edit 的延迟足够低，写小改动时不会打断心流；遇到大任务切到 agent 模式。

**不适合**：需要完全可复现、可审计的执行环境；也不适合当无人值守的批处理用。它本质是给人用的编辑器。

**和其他工具比**：Cursor 是我唯一离不开的 IDE 形态工具，但它和 CLI 类 Agent 不在同一个维度上：Cursor 让人写得更快，CLI Agent 让机器干得更多。真正做长任务时我仍然会开终端 Agent，把 Cursor 当成写代码和 review diff 的地方。
