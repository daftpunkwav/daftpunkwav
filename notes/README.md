# 笔记

这个目录放两类个人笔记。不是产品文档，也不是给别人看的教程，是我自己用的记录。

| 目录 | 内容 | 写法 |
| :--- | :--- | :--- |
| [agents/](agents/) | 我实际用过的 AI 编程 / 通用 Agent 工具：形态、架构特点、我拿它干什么、什么情况下会打开它 | 客观描述 + 一句话结论，不排名、不吹捧、不贬低 |
| [concepts/](concepts/) | 我对具体技术与概念的评价：它解决什么、什么时候值得用、什么时候是坑 | 先给判断，再给依据，最后落到我自己写过的项目上 |

## 约定

这几条是我给自己定的规矩，也是这个目录和网上那些推荐清单不一样的地方：

- **可佐证**：结论尽量能追到源码、官方文档或公开资料；追不到的直接标未确认，不靠印象补全。
- **两面都写**：每个东西都写清楚适合什么和不适合什么。只写好处的笔记没有参考价值。
- **不下判断排名**：工具之间不做打分排序，因为我的场景和别人的场景不一样，排名没有意义；只记录在什么场景下我选它。
- **落到项目**：涉及技术判断的地方，尽量指回我自己仓库里的实现，而不是停留在概念层面。
- **中性命名**：目录和文件命名保持中性，不做神级 / 垃圾这类标签，因为一年后回头看，多数评价都会变。

## 维护

内容会随着使用持续补充。工具换得比较快，所以 [agents/](agents/) 里的结论带时间属性，写的都是截至当时的状态；[concepts/](concepts/) 里的判断变化慢一些，更接近长期结论。
